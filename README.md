# Python Basic Project

This is a beginner Python project for calculating student marks and percentage

## Features

- Student name and age input
- Marks input
- Total marks calculation
- Percentage calculation
- Grade calculation
- Uses basic Python concepts

## Python Concepts Used

- Variables
- Input and Output
- Data Types
- Arithmetic Operators
- If/Elif/Else Conditions
- Type Conversion

## How to Run

Run the following command:

python main.py
